# E-Commerce Sales & Customer Behavior Analysis

## Project Overview

This project focuses on analyzing e-commerce order data to understand
purchasing behavior, payment preferences, delivery performance, and
customer satisfaction.

The project is being developed as an end-to-end data analytics project
using Excel, MySQL, Python, and Power BI.

## Objectives

- Understand the structure and quality of the dataset
- Analyze e-commerce purchasing behavior
- Analyze payment methods and order values
- Study delivery performance
- Explore customer review patterns
- Identify meaningful business insights
- Build an interactive Power BI dashboard

## Tools & Technologies

- Excel
- MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Power BI
